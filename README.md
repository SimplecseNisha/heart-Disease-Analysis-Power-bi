# heart-Disease-Analysis-Power-bi
Heart Disease Analysis Dashboard built with Power BI — interactive visualizations exploring risk factors, patient demographics, and disease patterns.
Heart Disease Analysis Dashboard
An interactive Power BI dashboard analyzing heart disease patient data 
to uncover survival patterns, age-related risks, and the impact of 
lifestyle & medical factors. Dashboard Overview

| KPI | Description |

| Survival Rate | Overall patient survival percentage |
| Avg Age of Survival | Mean age among surviving patients |
| Total Survival | Count of survived patients |
| Total Deaths | Count of patient deaths |

Visuals Included

- **Survival Count & Avg Serum Creatinine by Age Group** — Identifies how creatinine levels correlate with survival across ages
- **Survival Count & Avg Ejection Fraction by Age Group** — Shows how heart performance varies among survivors
- **Survival Rate by Age Group** *(Line Chart)* — Tracks age-related survival trends
- **Ribbon Chart** — Impact of smoking, high blood pressure, diabetes & anaemia across age groups
- **Sex Slicer** — Filter all visuals by patient gende

Tools Used

- Power BI Desktop — Dashboard & visuals
- Power Query — Data cleaning
- DAX — KPI calculations
- Canva — Background design
